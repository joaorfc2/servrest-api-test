## ServeRest API Test

Projeto de automação de testes de API desenvolvido em Java utilizando RestAssured, com foco em:

Separação de responsabilidades
Reutilização de código
Clareza dos testes
Facilidade de manutenção
Utilização de arquivos skill.md para agentes de IA, detalhando as responsabilidades e exemplos de cada componente do projeto.

O projeto utiliza a API pública do ServeRest como sistema sob teste.

## Tecnologias Utilizadas

Java 17
Maven
RestAssured
TestNG
Jackson
Lombok
Hamcrest
JSON Schema Validator
